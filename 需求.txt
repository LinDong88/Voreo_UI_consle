当前已实现功能（UI_console）

协议对齐固件 README「USB 虚拟串口 AT 指令」（UsbVcom.*）。

【运行方式】
  - 双击 启动.bat：启动串口桥接 + Web 界面，并打开 http://127.0.0.1:5173/
  - 双击 停止.bat：结束占用 5173 / 5174 的进程
  - 或在项目目录执行：npm run dev

【连接与串口】
  - 自动扫描并优先识别 Espressif USB Serial/JTAG（Voreo）
  - 手动选择串口、连接 / 断开
  - 连接后自动查询：AT+VER? / AT+VOL? / AT+SPD? / AT+WAKEWORD?
  - 显示当前串口、固件版本、设备日志
  - 中英文界面切换

【语音交互 · URC】
  - +WAKE     唤醒
  - +ASR:<text>  识别文字 → 对话区
  - +VER:<ver>   版本通知
  - 手动 TTS：AT+TTS=<utf8>
  - 停止 / 打断本轮 LLM 回复（上位机侧）

【设备 AT 命令】
  - AT+VOL=<0~15> / AT+VOL?     音量设置 / 查询
  - AT+SPD=<0~15> / AT+SPD?     语速设置 / 查询
  - AT+ANGLE?                   读 DOA 角度 → +ANGLE:<deg>
  - AT+WAKEWORD=<word> / ?      设/查英文唤醒词（恢复默认 HI ESP）
  - 成功末行 OK，失败末行 ERROR

【大模型】
  - 可配置 API 地址 / Key / 模型，保存到本地
  - 勾选「ASR 后自动回复并 TTS」后，识别结果可自动请求 LLM 并 AT+TTS 播放
  - 勾选「未配置大模型时使用演示回复」后，未配置 API 才走固定演示回复；未勾选则不自动回复

【界面结构】
  - 左侧：对话、TTS 输入、声源定位罗盘（刷新 = AT+ANGLE?）
  - 右侧：串口状态；「设备 / 智能」分页（设备设置 + 唤醒词 / 大模型）；设备日志
